# Contributing to Welvox Skill Lab

Thanks for helping. Here is how to suggest a skill.

## Add a skill

1. Open an issue titled `Add skill: <name>`.
2. Include: source link, license, which agents it works with, and a one-line purpose.
3. Only free skills with a clear license are listed.

## Rules

- Link to the original source. Do not paste other authors' files.
- No claims we cannot back up.
- Skills that fail the safety check are not listed.

## Report a problem

Open an issue with the skill name and what is wrong.
