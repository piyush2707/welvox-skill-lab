# Welvox Scoring Rubric

Every "Checked" skill gets a score out of 100. The rules are public and fixed, so scores can be questioned.

| Category | Points | What we look at |
|----------|--------|-----------------|
| Safety | 30 | No hidden commands, no sending data elsewhere, no unexplained scripts |
| Clarity | 20 | Clear description, clear steps, valid SKILL.md frontmatter |
| Usefulness | 20 | Solves a real problem, tested with a real task |
| License | 15 | License is stated and allows free use |
| Maintenance | 15 | Updated recently, issues answered |

## Rules

- A skill with a safety concern cannot be marked Checked.
- If we did not test it, the entry says "untested". We never guess.
- Scores can change. Every entry shows its last-checked date.
- We link to original sources. We never copy other authors' files.
